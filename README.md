# Dippi Ki Rasoi — First Website

A zero-cost, mobile-friendly starter website for Dippi Ki Rasoi.

## Files
- `index.html` — website structure/content
- `style.css` — design and responsive layout
- `script.js` — mobile menu + footer year

## Before publishing
Replace these placeholders in `index.html`:
1. YouTube URL
2. WhatsApp URL
3. Email address
4. Recipe cards with real recipe links
5. Emoji placeholders with your own food photos

## Free hosting
This site can be published on GitHub Pages without buying hosting.

Basic flow:
1. Create a GitHub account.
2. Create a repository named `dippikirasoi.github.io` (if available).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
4. Open repository Settings → Pages.
5. Select deployment from the main branch.
6. GitHub will provide the live website URL.

No paid hosting is required.
